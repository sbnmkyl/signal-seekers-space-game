# Signal Seekers · Sinyal Avcıları

Signal Seekers is a bilingual, animated educational web game for young space enthusiasts. Players join Piko, a tiny signal-repair robot, to recover the memories of robotic explorers on the Moon, Mars, and in deep space.

## Live Game

[Play Signal Seekers](https://sbnmkyl.github.io/signal-seekers-space-game/)

## The Story

The year is 2060. Signals from historic robotic explorers are fading from the Cosmic Memory Network. Players restore each signal by completing a short science-based mission, listening to a creative memory transmission, and answering a mission question.

## Missions

- **The Laser Bridge:** Aim a laser at a lunar retroreflector and learn how scientists measure the Earth–Moon distance.
- **Traces of Water:** Guide Opportunity across Mars and collect mineral clues connected to ancient water.
- **The Impossible Flight:** Fly Ingenuity through the thin Martian atmosphere.
- **The Heart of Mars:** Repeat seismic patterns recorded by InSight and reveal the layers of Mars.
- **A Letter to the Stars:** Guide Pioneer 10 through deep space and recover the pieces of its plaque.

## Features

- Turkish and English language support
- Five original mini-games
- Responsive desktop, tablet, and mobile controls
- Keyboard, mouse, and touch support
- Sound and reduced-motion options
- Progress saved locally in the browser
- Unlockable Cosmic Museum
- Personalized Memory Keeper certificate
- Mission facts linked to official NASA resources

## Technology

The project is build-free and uses only:

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- Web Audio API
- Local Storage

No installation or external package is required.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
